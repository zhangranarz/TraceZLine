Sources source="…" blocks joined with OR
Search terms

One per line (or comma separated), e.g. session IDs. Each is quoted and joined with OR. Leave empty to drop the line.

Layers LayerName=case() and Layer=case()

Condition is an SPL eval expression, inserted as typed. Order matters: the first match wins.

Direction rules Direction=case()

Rules below: regex is inserted into match(_raw,"…") as typed. case() uses the first rule that matches.

Endpoint rules rex + Endpoint=coalesce()

Field order is coalesce() order. A rule with an empty rex is only added to coalesce().

sessionId rules rex + coalesce()

Field order is coalesce() order. A rule with an empty rex is only added to coalesce().

Params rex + Params=mvappend()

Each param becomes "Label=value" in the Params column when present.
